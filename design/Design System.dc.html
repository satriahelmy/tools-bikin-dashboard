Buttons & links

No pill buttons. Primary actions are outlined or plain text with an accent color — weight comes from typography, not shape.

Tabs / filter chips

Underline tabs, not pills — active state is weight + accent underline, not a filled background.

Icon tiles

One consistent tile: 38px, 8px radius, accent-tint background. Glyphs are simple CSS shapes at one opacity family, never full-color illustration.

Card & list row

Cards are for tools only — hairline border, no shadow, no color. Reference content (resources, chart rows) lives in plain bordered list rows, not cards, so it stays scannable.

Principles

  • One accent color, used with intent — not decoration.
  • Borders and typography establish hierarchy before shadows or containers.
  • Not everything is a card — reference content lives in scannable list rows.
  • Icons stay consistent in size and construction across every context.
  • Active/selected state = weight + accent, never a filled pill.
