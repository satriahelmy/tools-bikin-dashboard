Masukkan palet ke alur kerjamu

Pilih format yang kamu butuhkan, lalu ikuti langkahnya.

Pasang palet di Tableau (TPS)

  1. Buka halaman Generator atau Dari Gambar, lalu siapkan palet.
  2. Klik tombol Ekspor Tableau TPS.
  3. File palette.tps akan diunduh.
  4. Buka folder Tableau: Documents/My Tableau Repository/Preferences/.
  5. Masukkan atau gabungkan isi file ke Preferences.tps yang ada (atau buat file baru).
  6. Mulai ulang Tableau, lalu pilih palet di workbook atau warna chart.

Simpan satu file TPS per proyek agar paletnya bisa dipakai lagi.

Pakai tema ini di Power BI (JSON)

  1. Buka halaman Generator atau Dari Gambar, lalu siapkan palet.
  2. Klik tombol Ekspor Power BI JSON.
  3. File theme.json akan diunduh.
  4. Di Power BI Desktop, buka View → Themes → Browse for themes.
  5. Pilih file theme.json yang sudah diunduh.
  6. Warna visual akan mengikuti dataColors dari palet.

Jika warna belum berubah, reset warna manual pada visual yang sudah ada.

Format lain

  • Salin variabel CSS untuk memasang palet di aplikasi web.
  • Ekspor PNG/JPG untuk dipakai di PowerPoint, Docs, atau tool lain.
